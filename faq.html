Need to know?

Frequently asked questions.

Quick answers about Netlify Music, downloads and supported platforms.

Is Netlify Music free?

The Android build linked on this website is available through GitHub Actions. Check the release details for the current build information.

How do I download the Android app?

Open the Downloads page and select the Android download button. It will take you to the GitHub Actions artifact you provided. You may need to sign in to GitHub to download workflow artifacts.

Is Windows supported?

Not yet. Windows is marked Coming Soon and will be listed here when a build is available.

What about Linux and macOS?

Linux and Apple macOS versions are not available yet. Their download cards will be updated when builds are ready.

Where can I find the source code?

Visit the Netlify Music GitHub repository using the GitHub link in the footer.

How can I report a problem?

Open the GitHub repository and use its Issues section to report bugs or request improvements.
